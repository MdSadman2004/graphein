## 2024-07-05 - [Contact Form Unbounded Payload Vulnerability]\n**Vulnerability:** Missing input validation and payload length limits on the contact form, leading to potential application-layer DoS.\n**Learning:** The frontend form silently lacked boundaries and allowed potentially massive strings in the Zustand store and on "submission", a common oversight in frontend SPAs without backend schemas directly tied to UI state.\n**Prevention:** Ensure `maxLength` is set on all relevant form elements and bounds checks exist before state mutations or API calls.
